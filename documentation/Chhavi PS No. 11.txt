Project Title -  College Attendance Analyzer
Problem Statement - Analyse student attendance from a CSV file to calculate attendance percentage, find students below the 75% requirement and show attendance patterns.

Language: Python 3      
Concepts: Pandas, CSV, Matplotlib, Filtering

Note: CSV columns: Name, Subject, Classes_Held, Classes_Attended. Minimum required attendance is 75%.
